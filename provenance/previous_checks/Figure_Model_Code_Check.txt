FIGURE AND CODE CHECK: NONNEGATIVE MODELS
Revised October 4, 2026

Canonical model retained for Section 4: DM_(5,2)
  dx_i/dt = a*x_i - k*x_i^2 + c*x_(i-1)/(1+x_i)
            - g*x_i/(1+x_(i+2)) - h*x_i*x_(i-2).
Indices wrap modulo five. Parameter order: (a,k,c,g,h).
Baseline: (2,0.5,1,0.5,0.3).
At x_i=0, the derivative is c*x_(i-1)>=0 on the nonnegative domain.
The exact equation preserves nonnegative states. Solvers have finite error.

canonical_model.py contains only this model, its positive synchronous
balances, its Jacobian, and a baseline calculation. canonical_model.ode
contains the same five expanded equations for XPPAUT.

Fresh checks on this version:
250 random-state Jacobian checks: maximum error 7.11e-15.
Boundary identity checks: exact agreement in these evaluations.
Expanded XPPAUT equations: maximum discrepancy 1.43e-14.
Both baseline disturbance simulations completed, stayed positive, and
returned to balance. The tested approach-to-zero trajectory remained positive.
These checks do not constitute a full XPPAUT application run.
