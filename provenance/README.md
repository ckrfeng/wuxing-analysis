# Import provenance

Imported on October 10, 2026 after approval of the proposed structure. `import_manifest.csv` records every retained, deduplicated, excluded and ZIP-container decision. `unique_import_files.csv` lists the 431 unique source-content files; full SHA-256 identities are preserved. The proposed manifest is retained to document the approved plan. Source originals remain in place.

`snapshots/` maps complete retained physical trees and ZIP member paths to shared repository content. `duplicate_content.csv` distinguishes byte identity from matching filenames. `figure_provenance.csv` and `model_equations_and_settings.txt` record equations and generator settings. `previous_checks/` contains prior numerical validation records, not new proof certifications. `th_complete_inventory.csv` covers all 1,565 old workspace files, including excluded dependencies/caches/rendering products.

`import_file_hashes.csv` records the final repository import file hashes, excluding itself and the final verification report to avoid circular hashes. `verification.json` records the import integrity and targeted run checks. No original was moved or deleted. No commit or GitHub push was performed by this import.
