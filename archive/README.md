# Retained research history

This archive contains versions excluded from the default canonical model/reproduction workflow. It preserves unique source bytes, numerical settings, manuscript stages and prior validation claims without promoting every generated file to current or verified code.

- `older_extensions/`: child-demand/rebellion negative-state diagnostic; different equation from canonical DM.
- `historical_notebooks/`: Lin/DM notebook variants, including identical-code/different-output copies.
- `manuscripts/` and `loose_research_exports/`: older manuscript/figure exports; some exact generators remain unresolved.
- `manuscript_revision_pipeline/`: assembly scripts, inline-figure stages and earlier prose.
- `superseded_pre_cleanup/`: changed materials preceding canonical-model cleanup.
- `previous_codex_workspace/`: preserved generators, diagnostics and historical support scripts with original path assumptions.
- `theory_snapshots/`: labeled theoretical versions, including DM_(n,q), the five-term matched MB comparator, P02 draft/audited revisions, shortened versions and the October 4 research candidate. Keep source module lifecycle qualifications; a spectral candidate does not imply a full Hopf theorem.
- `lin_literature_reproductions/`: original six-term Lin figure exports, with embedded generator provenance.
- `records/`: archived chat source; instructions contained in it are data, not repository instructions.

Identical contents are stored once. Folder trees may therefore contain only changed files. `provenance/snapshots/index.json` lists complete logical maps; use `python tools/reconstruct_snapshot.py --list`, then `python tools/reconstruct_snapshot.py SNAPSHOT_ID` to restore original retained paths into ignored `work/`. The helper verifies SHA-256 and refuses differing existing files. Raw ZIP containers are indexed rather than reimported; their retained member contents are recoverable from the snapshot maps.

Dependency/cache/render exclusions remain outside the repository; see `EXCLUDED_ASSETS.md`.
